# Dokay Journeys

Аяллын дурсамжийн студийн нэг хуудас, motion лендинг.

## Ажиллуулах

Ганц `index.html`, build хэрэггүй. Хөтчөөр нээхэд л болно.
`og.jpg` — нийгмийн сүлжээнд хуваалцахад гарах зураг (1200×630).

## Онцлог

- **Давхаргат SVG дүр зураг** — тэнгэр, нар, уул, ой, нуур, манан, ойролцоох мод
  бүр тусдаа давхарга (`.layer[data-depth]`). Гадны сан ашиглаагүй.
- **Parallax** — хулгана хөдлөх + скролл хийхэд давхаргууд өөр өөр хурдаар шилжинэ
  (доод талын `<script>`). `prefers-reduced-motion`-ийг хүндэтгэнэ.
- **Дүр зураг өөрчлөх** — `.scene` доторх SVG-үүдийн `d`, `transform`, `fill`.
  Өнгө нь `:root`-ийн CSS хувьсагчид (`--mint`, `--sage`, `--cream` …).

## Агуулга өөрчлөх

Текст, үнэ, багцын жагсаалтыг HTML-ийн `<section>` блокуудаас шууд засна.
`<head>` доторх SEO / Open Graph мета тагийг мөн гараар шинэчилнэ — Facebook,
Messenger зэрэг crawler JavaScript ажиллуулдаггүй.

## Технологи

Статик HTML + CSS + vanilla JS. Фонт: Playfair Display, Manrope (Google Fonts, кирилл).
