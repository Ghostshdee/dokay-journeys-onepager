# Dokay Journeys

Аяллын үйлчилгээний нэг хуудас танилцуулга.

## Ажиллуулах

Ганц файлтай, build хэрэггүй. `index.html`-ийг хөтчөөр нээхэд л болно.

## Агуулга өөрчлөх

Бүх текст, огноо, нэр, холбоо барих мэдээлэл нь `index.html`-ийн дээд талын **`CONFIG`** объектод байна. Зөвхөн тэндээс өөрчилнө — HTML/CSS-д гар хүрэх шаардлагагүй.

<head> доторх SEO болон Open Graph мета таг нь үл хамаарах зүйл: Facebook, Messenger зэрэг crawler JavaScript ажиллуулдаггүй тул тэдгээрийг тусад нь гараар шинэчилнэ.

## Технологи

Статик HTML + CSS, Google Fonts
